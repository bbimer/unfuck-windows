## Горячие клавиши (Управление окнами как в Windows)

### Базовые снапы и позиционирование (Alt + Стрелки / Win + Стрелки)
| Комбинация | Действие |
|---|---|
| `Alt + Up` / `Win + Up` | **Развернуть окно на весь экран** (Monocle). Повторное нажатие возвращает обратно в сплит. |
| `Alt + Down` / `Win + Down` | **Свернуть окно** (Minimize) / вернуть из полного экрана. |
| `Alt + Left` / `Win + Left` | **Прижать / переместить окно влево**. |
| `Alt + Right` / `Win + Right` | **Прижать / переместить окно вправо**. |

### Навигация и фокус
| Комбинация | Действие |
|---|---|
| `Alt + Ctrl + Стрелки` | Переключить фокус между окнами (влево/вправо/вверх/вниз) |
| `Alt + Shift + [` / `]` | Циклический фокус между окнами |
| `Alt + Shift + Enter` | Сделать активное окно главным (Promote) |

### Пластичность и манипуляции
| Комбинация | Действие |
|---|---|
| `Alt + F` | **Toggle Float** — отвязать окно от тайлинга (свободное перемещение/ресайз как в обычной Windows) |
| `Alt + Q` | **Retile** — принудительно пересчитать сетку окон |
| `Alt + P` | **Pause** — временно приостановить тайлинг для всех окон |
| `Alt + X` / `Alt + Y` | Перевернуть ось сплита (по горизонтали / по вертикали) |

### Воркспейсы (Рабочие столы)
| Комбинация | Действие |
|---|---|
| `Alt + 1 .. 8` | Переключиться на рабочий стол 1 .. 8 |
| `Alt + Shift + 1 .. 8` | Перенести активное окно на рабочий стол 1 .. 8 |
