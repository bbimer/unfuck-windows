## Умный снап окон (Smart Snap AHK v2)

Скрипт `ahk/snap.ahk` заменяет жесткий и глючный авто-тайлинг на **настоящий пластичный снаппинг**, заточенный под 27" монитор и статус-бар YASB:

### 2 окна (Сплит 50/50)
* **`Alt + Left`** (или `Win + Left`) — мгновенно прижать окно к левой половине (50%).
* **`Alt + Right`** (или `Win + Right`) — мгновенно прижать окно к правой половине (50%).

### 3 окна на 27" (3 колонки по 33%)
* **`Alt + Left`** (нажать дважды) — окно встает в **левую треть (33%)**.
* **`Alt + C`** — окно встает в **центральную треть (33%)**.
* **`Alt + Right`** (нажать дважды) — окно встает в **правую треть (33%)**.

### 4 окна (Сетка 2x2 по углам)
* Окно слева + **`Alt + Up`** — верхний левый угол (25%).
* Окно слева + **`Alt + Down`** — нижний левый угол (25%).
* Окно справа + **`Alt + Up`** — верхний правый угол (25%).
* Окно справа + **`Alt + Down`** — нижний правый угол (25%).

### Полный экран и сворачивание
* **`Alt + Up`** (на любом окне) — развернуть окно на всю рабочую область под YASB.
* **`Alt + Down`** — свернуть окно.

### Навигация и фокус
| Комбинация | Действие |
|---|---|
| `Alt + Ctrl + Стрелки` | Переключить фокус между окнами (влево/вправо/вверх/вниз) |
| `Alt + Shift + [` / `]` | Циклический фокус между окнами |
| `Alt + Shift + Enter` | Сделать активное окно главным (Promote) |

### Пластичность и манипуляции
| Комбинация | Действие |
|---|---|
| `Alt + F` | **Toggle Float** — отвязать окно от тайлинга (свободное перемещение/ресайз как в обычной Windows) |
| `Alt + Q` | **Retile** — принудительно пересчитать сетку окон |
| `Alt + P` | **Pause** — временно приостановить тайлинг для всех окон |
| `Alt + X` / `Alt + Y` | Перевернуть ось сплита (по горизонтали / по вертикали) |

### Воркспейсы (Рабочие столы)
| Комбинация | Действие |
|---|---|
| `Alt + 1 .. 8` | Переключиться на рабочий стол 1 .. 8 |
| `Alt + Shift + 1 .. 8` | Перенести активное окно на рабочий стол 1 .. 8 |
